SHOPBOT — Order-cost system, now GATED per-tenant (Shree only)
Adds window.SHOP_FEATURES.order_system flag. Links hidden + routes 404 unless enabled.

CHANGED vs previous drop — 3 gate files:
  app/Http/Controllers/Panel/SellerPanelController.php   injects the feature flag
  app/Http/Controllers/Panel/OrderCostController.php     page methods 404 if flag off
  app/Http/Controllers/Panel/CashPositionController.php  page 404 if flag off
  resources/panel/seller.html                            links wrapped, shown only when flag on

DEPLOY: commit + push -> Deploy -> php artisan migrate -> php artisan storage:link

ENABLE FOR SHREE ONLY: run the Chrome script (below) OR tinker:
  $t = \App\Models\Tenant::where('slug','shree')->first();   // or find(ID)
  $t->putSetting('order_system_enabled', true);
  // to also require approval (imprest): $t->putSetting('cost_approval', true);

DISABLE for any tenant: putSetting('order_system_enabled', false)  -> links vanish, routes 404.
