DEPLOY
------
Copy app/, resources/, routes/, bootstrap/ over your repo. routes/web.php and bootstrap/app.php
each have only a 1–2 line addition — merge by hand if your copies diverged since upload.
src/ and the *.py are dev tooling (to rebuild autoparts.html); the shipped autoparts.html is
already self-contained.

RUN TESTS
---------
  cd storefront-tests && npm install && npx playwright test        # 26 pass
  php artisan test --filter StorefrontBotGuardTest                 # in your app (vendor/DB)

REBUILD THE STOREFRONT (after editing a src/ module)
----------------------------------------------------
  python3 build_storefront.py           # writes resources/storefront/autoparts.html
