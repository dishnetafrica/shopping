DEPLOY — Phase 3: FX recognition, manual journals, period lock, reconciliation (v48)
====================================================================================
Completes the controls + FX gaps from the CFO audit. Builds on Phases 1 & 2. All new
tools live in the Financial Statements page (Tools + Reconcile tabs). Owner/manager/
accounts only.

WHAT'S NEW
  1. PERIOD LOCK — set a lock date; no journal (live posting or manual) can post on/before
     it. Close a month once reviewed. (Tools tab.)
  2. MANUAL JOURNALS — a proper balanced Dr/Cr entry screen. Debits must equal credits.
     This is how your accountant posts tax, accruals, prepayments, provisions, opening
     balances and corrections — correctly — without hard-coded guesses.
  3. FX RECOGNITION (realized) — "Recognize FX" sweeps the FX Clearing suspense into
     FX Gain/Loss. Run after conversions.
  4. FX REVALUATION (unrealized) — restate UGX/SSP cash at today's rate; posts the
     difference to FX Gain/Loss. (Verified: UGX 4,700,330 @ 3700 => USD 1,270.36, books a
     15.64 loss vs a 1,286 carrying value.)
  5. RECONCILIATION — Reconcile tab compares the ledger's cash (per currency) with the
     operational cashbook and flags any drift (should be 0).

HOW TO USE (typical month-end)
  a) Rebuild ledger (or leave live posting ON so it's already current).
  b) Reconcile tab -> confirm drift is 0 per currency.
  c) Tools -> Recognize FX (sweeps conversion differences to P&L).
  d) Tools -> Revalue UGX/SSP at month-end rate (unrealized FX).
  e) Post any manual journals (tax, accruals, adjustments).
  f) Tools -> set the Period lock date to close the month.
