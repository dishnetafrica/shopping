UPLOAD TO GITHUB — friendly per-model ON/OFF toggles
=====================================================
Settings → Storefront now shows a switch for each bike model (no more typing names):
    Boxer 100 KS      [ON]
    Boxer 125 HD      [ON]
    Boxer BM150       [ON]
    Boxer BM125X      [ON]
    Boxer BM150 X     [ON]
Flip one OFF to hide that model from the website, ON to show it, then Save.

FILES (drag BOTH the "app" AND "resources" folders — they replace existing files):
  app/Support/Vertical.php
  app/Support/SettingsSchema.php                             (toggles replace the text box)
  app/Services/Settings/SettingsWriteService.php             (saves the toggles)
  app/Http/Controllers/Storefront/StorefrontController.php   (reads the toggles)
  resources/storefront/autoparts.html                        (self-contained storefront)

** IMPORTANT — the resources file must land too **
Last time the admin updated but the website did not. That means your deploy
picked up the app/ folder but NOT resources/storefront/autoparts.html.
After deploying, confirm the website file updated by opening the storefront and,
in the Console (F12), running:
    fetch(location.href).then(r=>r.text()).then(t=>console.log('site updated:', t.includes('function activeModels')));
It must print TRUE. If it prints FALSE, the resources/ folder didn't deploy —
make sure that folder is included in your upload/commit.

DEPLOY:  git pull  ->  php artisan optimize:clear  ->  restart  ->  hard-refresh (Cmd/Ctrl+Shift+R)
