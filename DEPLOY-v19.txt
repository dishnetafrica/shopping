DEPLOY — Sourcing Requests: Asish -> Jayesh (v19)   [cumulative]
================================================================
Asish (field, South Sudan) logs items customers want but you don't stock, and asks
Jayesh (purchaser, Uganda) to find a price. Jayesh prices it; Asish sees the price
to quote the customer. The item does NOT need to exist in the catalogue.

FLOW
  1. Asish: "New request (get me a price)" -> item name + optional photo + note +
     demand (Low/Medium/High). Status = NEEDS PRICE.
  2. Jayesh: opens the request -> "Add price" -> price found + currency + supplier +
     availability + note. Status = PRICED.
  3. Asish sees the price on the card -> quotes the customer. "Mark done" closes it.
  A "WhatsApp" button on each request shares the text (opens WhatsApp).
  Counts at top: Needs price / Priced. New requests sort to the top.

  Access = anyone with the trading panel (Asish posts, Jayesh prices, both see).
  Isolated table; nothing touches the catalogue or orders.
