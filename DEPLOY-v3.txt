Now: he books ONE buy and splits it across the orders it served. Each order
gets only its slice, cash drops by the full amount once, one receipt is shared.

WHAT v3 ADDS
  Migration: order_costs.purchase_group_id (nullable, indexed) — groups the split rows
             from one buy. Additive, no existing column touched.
  Endpoint : POST /papi/order-costs/bulk  (OrderCostController::bulkStore)
             - inputs: currency, rate_to_usd, total_native, method(qty|value|even),
               stage, note, receipt(file), holder rules (same as store()), orders JSON.
             - writes N order_costs rows in ONE DB transaction, all sharing rate/holder/
               receipt/purchase_group_id.
             - SPLIT ALWAYS SUMS TO total_native to the cent (last row absorbs the
               rounding remainder) -> cash never leaks, no order over/under-charged.
             - method qty  = weights are the typed quantities
               method value= weights are each order's USD revenue (currency-aware, server-side)
               method even = equal shares
             - status follows tenant 'cost_approval' (pending) just like single booking.
  UI (book_cost.html): a "One order | Split across orders" toggle. Split reveals method
             chips (By quantity default / By order value / Even), a tick-list of orders
             with a qty box each, and a live green breakdown showing每 order's share +
             USD, confirming it equals what was paid. One tap books all.
             The single-order flow is UNCHANGED (added as a separate script; save() intact).

MONEY-PATH SAFETY
  - Gated to Shree via order_system_enabled (endpoint aborts 404 otherwise).
  - Allocation verified to sum exactly for qty / value / even incl. odd rounding
    (100/3 -> 33.33/33.33/33.34 ; 1000/7 sums to 1000).
  - Amounts posted are digits only (commas stripped client-side, like the rest).
  - DRY-RUN first: before real use, book a split for 2 test orders with a small
    amount, then open each order (Orders & Margin -> tap) and confirm the shares +
    that Cash Position dropped by the single total. Delete the test rows after.
