DEPLOY — Notify Jayesh on WhatsApp when Asish posts (v20)
========================================================
When Asish sends a sourcing request, it now opens WhatsApp to Jayesh with the
request text, so he's pinged immediately. Front-end only.

FILE CHANGED (one)
  resources/panel/sourcing.html

HOW IT WORKS
  - One-time: tap "Set Jayesh's WhatsApp" (top-right of the Requests list) and enter
    Jayesh's number with country code (e.g. 2567XXXXXXXX). Stored on the device.
  - After Asish saves a request, WhatsApp opens to Jayesh pre-filled with:
        *New sourcing request*
        Item: ...
        Demand: ...
        Note: ...
        Please find a price.
    Asish taps send, then returns to the app.
  - If no number is set yet, it just saves (no WhatsApp) until you set the number.
  - Each request's "WhatsApp" button also uses Jayesh's number when set.
