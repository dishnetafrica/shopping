MODERN CUSTOMER 360 — second real-app screen on the design system v1.0
======================================================================

WHAT
  The customer screen (bosTimeline) is rebuilt to the frozen design — the same treatment Today got —
  with REAL data, no mocked figures.
    • Avatar + name + city·phone header.
    • ★ relationship score (1–5) computed from real behaviour: has lifetime, owes nothing now, within
      credit limit. Label: Top customer / Regular / Needs attention.
    • Stats strip: Outstanding (live invoices) · Lifetime (sum of this customer's payments) · Last order
      (most recent order date) · Credit standing (Good/Watch/Over vs the profile's credit_limit).
    • The honest Order-to-Cash rail + next step (unchanged, kept).
    • History with filter chips (All / Payments / Invoices / Visits) and SVG-icon timeline rows
      (no functional emoji, per the design freeze), payment/invoice amounts shown large.

  resources/views/shell.blade.php                modern bosTimeline() + bosTLine() + bosTlf() + .c360-* CSS

VERIFY ON A PHONE
  Open a customer -> the new header/score/strip, the rail, and the filter chips. Tap Payments/Invoices/
  Visits -> the history filters. All figures are live (lifetime rises as payments are recorded).

SAFETY
  Additive read-only backend query (lifetime/last-order); no migration, no money-path write. The score is
  a display heuristic from real fields, documented in the code — not a stored/mocked value.
