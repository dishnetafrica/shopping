DEPLOY — Edit / Delete a purchase from the Supplier view (Purchase CRUD)
=======================================================================
Fixes: "I made a mistake entering a purchase and can't correct it."
Adds Edit + Delete (void) actions to each purchase row inside the Suppliers screen
(/panel/suppliers -> View a supplier -> Purchases table).

Also adds the same Edit + Delete on the standalone "New Purchase" screen
(/panel/purchases -> Recent purchases), so a wrong line can be fixed right where it was entered.

WHAT'S NEW
  - Each purchase line now has an "Edit" and a "Delete" button (both in the Supplier view's
    Purchases table AND in the Recent-purchases list on the New Purchase screen).
  - Edit: correct the item/description, qty, unit cost (or amount), currency and
    cash/credit. If the line has qty x unit cost, the amount recalculates automatically;
    amount-only lines let you type the corrected amount directly.
  - Delete: VOIDS the line (soft delete). Financial history is never physically erased —
    the row is marked "void", drops out of the Owed balance, and stays in the audit trail.
  - Both actions are owner/manager only, are blocked in a locked accounting period, and
    are written to the audit log (before/after values + optional reason). This respects the
    existing frozen accounting controls — nothing bypasses the period lock or the ledger.
  - When live GL posting is on, editing a line auto-reverses the old journal and posts the
    corrected one (handled by the existing OrderCostObserver — no extra work).
