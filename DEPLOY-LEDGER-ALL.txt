DEPLOY — Double-Entry Ledger, Phases 1+2+3 combined (v52)
=========================================================
One upload, one migrate. This is the full accounting-engine foundation from the CFO audit:
a real double-entry general ledger derived from your cashbook, made live + immutable, with
FX recognition, manual journals, period lock and reconciliation. It is ADDITIVE and ships
DORMANT — deploying changes nothing your staff see until you turn "Live posting" ON.

WHAT'S INCLUDED (all three phases)
  Phase 1 — Chart of accounts + journals + lines; derive a balanced GL from order_costs;
            Trial Balance / Balance Sheet / P&L reports; `ledger:backfill` command.
  Phase 2 — Live write-time posting via an OrderCost observer (dormant behind a toggle);
            append-only immutability (edits/deletes post REVERSING journals, never delete).
  Phase 3 — Period lock, manual journals, FX realized (clearing sweep) + unrealized
            (revaluation), and GL↔cashbook reconciliation.
  Also includes the v51 fix: the observer is inert (Schema::hasTable guard) until these
  tables exist, so it can never poison a transaction.

DEPLOY (in order)
  1. Unzip -> GitHub upload (keep folder paths) -> Commit -> EasyPanel REBUILD (not Restart).
  2. Run migrations:   php artisan migrate
       (creates ledger_accounts, ledger_journals, ledger_lines, ledger_config, + lock_date)
  3. Build the ledger:  php artisan ledger:backfill
       (or open Financial Statements -> "Rebuild ledger")
  4. Open Financial Statements (sidebar) and CHECK:
       - Trial Balance says "In balance".
       - Reconcile tab: drift 0 per currency.
       - Balance Sheet: assets = liabilities + equity (any gap here = receipts without a
         sales invoice, or unreconciled FX — both are surfaced, not hidden).

WHEN THE STATEMENTS LOOK RIGHT
  - Tools tab -> Recognize FX (sweeps conversion differences to P&L).
  - Tools tab -> turn "Live posting" ON. From then on every cash entry auto-posts a journal,
    and edits/deletes post reversing entries. Your cashbook is unaffected.
  - You can turn Live posting OFF anytime; `ledger:backfill` always rebuilds from scratch.
