DEPLOY — EVERYTHING in ONE bundle (master checklist)
====================================================
This single zip contains all of today's features, already merged (each file is the latest version
with every change applied). Deploy once. ONE database migration is required (the Invoices register).

SAFE-DEPLOY STEPS (do these; nothing here wipes your data or settings)
  1. Replace ALL the files in this zip -> commit.
  2. php artisan migrate --force        (creates the 3 Invoices tables; additive, safe)
  3. EasyPanel REBUILD (force / no-cache) — restarts the queue worker + scheduler.
  4. Set on /panel/ads → "Bot behaviour":
       - Ad page/brand names to ignore:  SkyTrips
       - Keep AI replying after I message a customer:  ON
       - Price basis city:  Juba
       - Warehouse / pickup location:  Luri, just outside Juba, South Sudan
       - (optional) turn ON the Virtual salesperson + set the re-order window
  NEVER run on production: migrate:fresh, migrate:refresh, db:wipe (these DROP data). A normal
  "migrate --force" only adds tables and is safe to run on every deploy.
