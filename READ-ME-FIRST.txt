UPLOAD TO GITHUB — "Sell only what we have" (hide out-of-stock parts)
====================================================================
New on/off switch for a parts business: hide anything you don't have in stock.

  v3 → Settings → Storefront → Availability →
      [ Show only parts in stock (hide out-of-stock) ]   ON / OFF

  • ON  = any part with 0 stock disappears from listings, search and browse.
          Parts with NO stock number set (untracked) still show as "to order".
  • OFF = everything shows (current behaviour).
  Exploded diagrams still show every part regardless (so the diagram stays complete).

Set your stock numbers on the Products page (or via import); the storefront follows.

FILES: app/Support/SettingsSchema.php, app/Services/Settings/SettingsWriteService.php,
       app/Http/Controllers/Storefront/StorefrontController.php, resources/storefront/autoparts.html
DEPLOY: upload "app" + "resources" -> git pull -> php artisan optimize:clear -> restart -> hard-refresh.
  Confirm:  fetch(location.href).then(r=>r.text()).then(t=>console.log('OOS toggle live:', t.includes('CFG.hideOOS')));  // TRUE
