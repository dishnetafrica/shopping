DEPLOY — V3 Tasks: CRM-style scheduling upgrade (filters, exports, agenda)
==========================================================================
Upgrades the /v3 Tasks screen to work like the DishNet CRM Scheduling page:
filterable job register, date range, bulk actions, CSV/PDF export, timed
tasks with duration, and a grouped-by-day Agenda view. Builds on the earlier
V3 Tasks bugfix (this bundle is CUMULATIVE — it contains that fix too, so it
deploys cleanly whether or not the previous bundle was applied).

WHAT'S NEW on /v3 -> Tasks
  REGISTER   Columns: Task · Client (order no) · Assignee · Due · Duration ·
             Priority · Status. Status chips: Open / In progress / Paused /
             Blocked / Closed. Overdue due-dates show red. Managers see every
             open task + the 150 most recent closed; staff see their own.
  FILTERS    Status, Assignee and Priority dropdowns + From/To due-date range
             + live search — all combine, count updates live.
  BULK       Tick rows (shift-click for ranges) -> "Mark done (n)". Order-
             workflow tasks advance to their next stage; ad-hoc just close.
  EXPORT     CSV button in the toolbar downloads exactly the filtered rows
             (works on every dated list, not just Tasks). "Export PDF" makes
             a branded A4 register via /api/v1/doc/tasks-export and follows
             the on-screen status/assignee/date filters.
  NEW TASK   Now takes a due DATE + TIME (datetime picker) and a Duration
             (30 min … Full day) stored as the job's planned minutes, shown
             in the Duration column — like the CRM's job duration.
  AGENDA     List | Agenda toggle (top right of the toolbar). Agenda groups
             the same filtered rows by day — time, task, details, status
             chip and the Start/Done buttons on each line. Today is
             highlighted; the choice sticks per screen while you work.
  STAFF      Staff can now Start and Done their own tasks from the screen
             (Start used to be manager-only and errored for staff).
