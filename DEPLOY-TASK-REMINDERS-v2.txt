TASK REMINDERS v2 — now with a login-free, per-person "My Jobs" page (the DishNet model)
========================================================================================

This SUPERSEDES the first task-reminders bundle. It's the complete feature: the twice-daily WhatsApp
digest PLUS a tokenized, no-login task page — exactly like DishNet's scheduling links.

THE FLOW NOW
  1. 09:00 & 14:00 (Juba) each assignee gets their WhatsApp digest (unchanged), but the link now opens…
  2. …their own "My Jobs" page — NO LOGIN, no token to refresh by hand:
        https://mycloudbss.com/jobs/{token}
     A clean mobile page listing only THEIR open tasks (overdue / open counts + each task), styled like
     DishNet's Job List. The token is per-person and changes every day (a fresh reminder carries a fresh
     token; yesterday's link still opens for a 1-day grace, then dies).
  3. Tapping a task opens the existing per-task page (/task/{nonce}) — also NO LOGIN — where they
     Accept / Start, Mark as done, and add a note. (That page already existed; we just link the list to it.)

  So a staff member never logs into the main portal: they tap the WhatsApp link → see their jobs → open one
  → mark it done. Independent, token-authenticated, daily-refreshing — the DishNet experience.

WHY IT'S SAFE (login-free but scoped)
  • The daily token is an HMAC of {tenant, user, date} signed with your APP_KEY — unguessable, and it
    authorizes ONE thing: viewing that user's own open tasks. It reveals no account access and no one
    else's tasks. Verified here: valid token round-trips, a tampered token is rejected, an old date is
    rejected, yesterday's is accepted (grace).
  • The /jobs and /task routes are rate-limited (throttle:30/min) to defeat guessing.
  • Task actions (accept/done/comment) run through the existing, already-deployed no-login task path.
