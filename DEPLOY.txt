═══ THE IMPREST DISCIPLINE (why cash stays correct) ═══
  - A booked cost starts as PENDING (tenant setting cost_approval, default on).
  - Cash Position counts ONLY APPROVED costs — so system cash = physical cash.
  - Owner/manager approves via Cost Approvals (sees the receipt photo).
  - To skip approval: set tenant setting cost_approval=false (costs auto-approve).
