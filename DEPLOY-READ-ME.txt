DEPLOY — All-in-one: Convert Currency button added (v43)
========================================================
Adds a "⇄ Convert" button to the Cashbook so you never need a console script for
conversions again. It records BOTH legs (money OUT of the source currency, money IN to
the target) in ONE server transaction — no more half-done conversions. Owner/manager only.

NEW IN THIS BUILD
  - Cashbook toolbar: "⇄ Convert" button (owner/manager). Opens a form:
      From currency + Amount out  ->  To currency + Rate (auto-suggested)  +  Held by  +  Date
    Live preview shows e.g. "USD 600 -> UGX 2,193,000". One tap writes both legs
    (cash_out of source + cash_in of target), both tagged "Conversion", both held by the
    chosen person (default: you), linked by matching notes.
  - Backend: new atomic endpoint POST /papi/trade-cashbook/convert (single DB
    transaction, so it can never leave a one-sided conversion).
  - Both legs carry the same USD value, so company USD value stays constant — the money
    just moves between currency pockets.

  Example (your case): From USD 600 -> To UGX @ 3655, Held by Bhavin ->
    USD book -600 (Bhavin), UGX book +2,193,000 (Bhavin). Done in one click.

INCLUDES EVERYTHING ELSE (Staff Cash, My Cash field app, receipt/cashbook edit + delete,
seller nav) — single upload.
