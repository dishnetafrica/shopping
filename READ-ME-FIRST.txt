Answers the production-readiness review ("freeze features; modularize the storefront with

WHAT CHANGED
------------
Backend (app/):
  * StorefrontController.php
      - recordEvent() also accepts 'search' and 'whatsapp' events.
      - NEW botGuard(): honeypot + per-IP rate limit (12/min) on placeOrder() and requestQuote().
  * SettingsSchema.php, SettingsWriteService.php, Vertical.php — unchanged (storefront model
    toggles, trust/delivery settings, hide-out-of-stock).

Storefront:
  * resources/storefront/autoparts.html  (REBUILT, deployable)
      - Analytics fire via sendBeacon('/event'): view, add, checkout (x2), search, whatsapp.
      - Font Awesome 4.7 + Inter + JetBrains Mono are now SELF-HOSTED (embedded woff2). No
        cdnjs / Google Fonts — works on a blocked or slow CDN (South Sudan connectivity).
      - XSS hardening: esc() now escapes single quotes; ids run through a sid() whitelist so a
        hostile product id can't break out of an onclick handler.
  * resources/storefront/shop.html
      - Hidden honeypot field on the checkout/quote form (feeds botGuard).

Tests:
  * storefront-tests/            — Playwright e2e (18 tests, desktop + 360px), all green.
                                   Covers catalogue, view/add/cart/checkout/search/whatsapp,
                                   XSS escaping, and "zero third-party requests + FA loads".
  * tests/Feature/StorefrontBotGuardTest.php — PHPUnit: honeypot + rate limit (runs in your CI).

Tooling:
  * build_storefront.py  — reproducible build (template + build/*.json -> autoparts.html,
                           with placeholder validation).
  * vendor_fonts.py      — vendors FA + fonts into the template (idempotent).

  * HARDENING-PLAN.md    — corrected review, what shipped, and the remaining P1/P2 roadmap.

DEPLOY
------
Copy app/ and resources/ over your repo (same paths) and deploy. Ensure
resources/storefront/autoparts.html and shop.html ship.

REBUILD THE STOREFRONT (after editing the template)
---------------------------------------------------
  python3 vendor_fonts.py         # (only if re-vendoring fonts)
  python3 build_storefront.py     # writes resources/storefront/autoparts.html

RUN TESTS
---------
  cd storefront-tests && npm install && npx playwright test     # 18 pass
  php artisan test --filter StorefrontBotGuardTest              # in your app (needs vendor/DB)

VERIFY LIVE (browser console on eaautopart.com)
-----------------------------------------------
  DevTools > Network: filter "event" (analytics fire), and confirm NO requests to
  cdnjs.cloudflare.com or fonts.googleapis.com (fully self-hosted).
