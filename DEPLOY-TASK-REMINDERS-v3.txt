TASK REMINDERS v3 — short DishNet-style job links (mycloudbss.com/jobs/Iu6BrElPjG)
=================================================================================

Same feature as v2 (twice-daily WhatsApp digest + login-free per-person "My Jobs" page), but the link is
now a SHORT code like DishNet's (e.g. /jobs/Iu6BrElPjG) instead of the long stateless token.

WHAT CHANGED vs v2
  • The per-person token is now a short random 10-char code stored on the user, stamped with the day it was
    minted. It rotates DAILY (the morning reminder issues a fresh code; yesterday's dies). Same security
    scope — it only opens that person's own task list, nothing else.
  • Requires ONE new migration: two nullable columns on `users` (job_token, job_token_day).

  ⚠️ NEW STEP: run `php artisan migrate` after deploy (adds the two columns). Guarded + additive.
